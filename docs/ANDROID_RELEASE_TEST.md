# Android 国内市场发布测试清单

## 自动检查

- [x] `npm run typecheck`
- [x] `npm run test:release`
- [x] `npx expo-doctor@latest`
- [x] `npx expo export --platform android`
- [ ] EAS `preview` APK 构建成功
- [ ] 最终 APK Manifest 中不包含 `RECORD_AUDIO`

## 安装与升级

- [ ] 全新安装后可正常启动，无白屏或闪退
- [ ] 从上一正式版本覆盖安装，旧衣物和穿搭自动迁移且图片完整
- [ ] 强制结束应用后重新打开，图片、分类、排序和穿搭仍然存在
- [ ] 飞行模式下可正常浏览、添加、裁剪和删除本地数据

## 图片来源

- [ ] 首次拒绝相机权限时应用不闪退，并显示清晰提示
- [ ] 再次允许相机权限后可以拍照并添加图片
- [ ] 相册支持单选和多选，取消选择不会新增数据
- [ ] 本地文件支持 JPG、JPEG、PNG、WebP、GIF、BMP、HEIC、HEIF
- [ ] 同一图片重复选择不会重复加入衣柜
- [ ] 添加后删除相册原图，重启应用后衣柜图片仍可显示

## 预览与裁剪

- [ ] 点击衣物图片进入预览，缩放与拖动正常
- [ ] 长按进入裁剪，四角均可调整裁剪矩形
- [ ] 再次裁剪不会保留上一次裁剪框的错误位置
- [ ] 裁剪保存后主页、详情和已有穿搭同时显示新图片
- [ ] 取消裁剪后原图不变

## 管理与删除

- [ ] 点击三个点时图片不闪烁、不缩小、不下移
- [ ] 单击图片可选择和取消选择
- [ ] 滑过多张图片可连续选择，再次滑过可取消选择
- [ ] 全选、取消全选和批量删除正常
- [ ] 删除被穿搭引用的衣物后，穿搭对应部位安全变为空白
- [ ] 删除后重启应用，不会恢复已删除数据

## 搭配与收藏

- [ ] 各部位选择、2.5D 拖动和裙装逻辑正常
- [ ] 保存到默认分类和自定义分类均正常
- [ ] 编辑已有穿搭后收藏页及时更新
- [ ] 穿搭预览、长按编辑、排序和批量删除正常

## 兼容与体验

- [ ] Android 7、10、13、15、16 至少覆盖三档系统版本
- [ ] 至少测试一台华为/荣耀和一台小米/Redmi 真机
- [ ] 首次启动、连续添加 10 张图片和包含 100 张图片时无明显卡顿
- [ ] 前后台切换、低电量模式和存储空间不足时不闪退
- [ ] 状态栏、底部导航、刘海屏和全面屏显示正常

## 隐私与审核

- [ ] 应用内可访问隐私政策
- [ ] 隐私政策说明相机、相册、本地文件和本地存储用途
- [ ] 隐私政策具有可公开访问的 HTTPS 地址
- [ ] 用户拒绝非必要权限后仍能使用不依赖该权限的功能
- [ ] 使用市场检测工具扫描无病毒、无恶意行为、无多余敏感权限
